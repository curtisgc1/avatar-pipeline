DEPLOYMENT INSTRUCTIONS
=======================
1. Configure brain server:
   cd ~/brain
   # Edit .env with actual values
   docker compose up -d

2. Configure jetson satellite:
   cd ~/jetson
   # Edit .env with brain IP and satellite ID
   docker compose up -d

3. Start Godot avatars:
   # 3D Avatar
   cd ~/brain/services/godot-avatar-3d
   godot --fullscreen

   # 2D Avatar
   cd ~/jetson/services/godot-avatar-2d
   godot --fullscreen
